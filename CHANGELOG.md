# Changelog

## 1.2.0 — 2026-10-15

### Back to the original purpose: diagnose the operating context

- Made context composition reconstruction the mandatory first deliverable, ahead of all 22 problem checks. A list of files or completed checkboxes no longer counts as a complete audit.
- Added `references/context-map.md`: seven source classes, five loading states, evidence-backed loading paths, A/B/C observation points, compatible measurement units and duplicate-counting rules. Unavailable runtime telemetry is explicitly unknown.
- Moved the context inventory, graph, measurement boundary and Doctor overhead to the top of the report template; require a partial-audit label if the structure cannot be supported.
- Retained the existing 22 checks, issue/verification split, evidence/counterevidence and non-executing approval handoff. Reduced the entry to 66 lines and stopped duplicating full domain procedures there.
- Updated platform guidance with host-observation hints, refreshed bilingual READMEs and repurposed 8 of 42 previously unrun scenarios to test real context-analysis failure modes instead of growing the checklist.

### Verification status

Source/ZIP structural validation and deterministic scenario indexing have been checked for this revision. The 42 behavioral evaluations remain **not run with real agents**; no claim about actual token savings, diagnosis accuracy or host sandbox enforcement.
